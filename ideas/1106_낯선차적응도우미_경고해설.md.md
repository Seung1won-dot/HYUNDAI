# 낯선 차 적응 도우미 (가칭)

현대자동차그룹 차량용 앱 개발 공모전 아이디어 정리본 (공개 SDK·API 제공 범위 기준 수정본)
분야: 안전 운전 / 모빌리티 라이프 케어

> 이 문서는 아이디어와 사용 방식만 정리한 문서입니다. 기술 스택과 구현 방식은 포함하지 않습니다.
> 기능은 Pleos Playground 공개 SDK·API 문서에서 제공이 확인된 차량 정보 범위 안에서만 구성했고, 값의 세부 내용이 확인되지 않은 항목은 "확인 필요"로 표시했습니다.

---

## 1. 한 줄 요약

처음 타는 차에서도 불안하지 않도록, 차량이 제공하는 경고와 상태를 쉬운 말로 해석하고 위험도를 알려주며, 출발 전 차량 상태를 요약해주고, 정비소에 정확히 전달할 수 있게 정리해주는 차량용 앱.

## 2. 배경과 문제 정의

### 시작은 팀원의 실제 경험

운전 경력 1~2년인 팀원이 본인 차가 아닌 차(타인의 차, 렌터카, 새 차)를 운전하면서 겪은 불편에서 출발했다.

- 와이퍼, 핸들, 기어 변경, 방향지시등처럼 기본 조작은 익숙하다.
- 그 밖의 버튼은 무슨 기능인지 몰라서 누르기가 망설여지고, 결국 차의 기능을 제대로 쓰지 못한다.
- 경고등은 차마다 모양과 위치가 달라서 헷갈린다.
- 경고등이 켜지면 "계속 타도 되는지, 지금 서야 하는지" 판단이 서지 않아 불안하다.
- 차 상태에 문제가 생겨 정비소에 가도, 정비 지식이 없어서 증상을 정확히 설명하거나 필요한 작업을 정확히 요구하기가 어렵다.

운전을 오래 한 사람도 차 상태를 정확히 알지 못하는 경우가 많다는 점에서, 이 문제는 초보에 국한되지 않는다. 이 경험은 설문과 사례 수집으로 보강할 예정이다.

### 핵심 불편

| 불편 | 설명 |
|---|---|
| 기능을 못 쓴다 | 낯선 차는 버튼의 위치와 의미가 달라 자주 쓰는 기능도 찾지 못한다 (기능 제어는 차량 내 음성 비서가 이미 담당하므로, 이 서비스는 해석과 안내에 집중한다) |
| 경고와 상태를 못 읽는다 | 경고의 모양, 위치, 의미가 차마다 달라 판단이 어렵다 |
| 물어볼 곳이 없다 | 운전 중에는 매뉴얼이나 검색을 할 수 없다 |
| 정비소에서 설명하기 어렵다 | 어떤 경고가 언제 떴는지 정확히 기억하거나 전달하기 어렵다 |

### 타깃 사용자

차를 자주 바꿔 타거나 처음 타는 차를 운전하는 사람, 그리고 차 상태를 잘 모르는 운전자

- 렌터카, 카셰어링 이용자
- 가족이나 지인의 차를 가끔 운전하는 사람
- 새 차를 막 인수한 사람
- 초보 운전자, 고령 운전자 및 이들을 모시는 가족

## 3. 해결 방식

"차의 말을 사람의 말로 바꾸고, 사람의 말을 정비소 말로 이어주는" 통역 역할을 한다.

| 단계 | 내용 |
|---|---|
| 해석 | 차량이 알려주는 경고와 상태가 무슨 뜻인지 쉬운 말로 알려준다 |
| 판단 | 지금 어떻게 해야 하는지 3단계 등급으로 알려준다 |
| 조치 | 가까운 충전소 또는 정비소 안내 등 다음 행동을 안내한다 |
| 전달 | 정비소에서 보여줄 수 있게 상황을 한 장으로 정리한다 |

### 해석과 판단의 대상

차량이 제공하는 정보를 사람이 정한 같은 규칙표로 해석하고 등급을 매긴다.

- 차량 경고 정보 (어떤 경고가 제공되는지는 확인 필요)
- 타이어 상태
- 문, 창문, 주차 브레이크 상태
- 배터리 또는 연료 잔량, 주행가능거리

경고 정보의 종류가 적더라도 상태 값만으로 서비스가 성립하도록 구성한다.

### 판단 3단계 (가안)

| 등급 | 안내 문구 | 예시 (제공이 확인된 정보 기준) |
|---|---|---|
| 계속 주행 가능 | 평소대로 운전하세요. 나중에 확인하면 됩니다 | 경미한 경고 (경고 종류 확인 후 확정) |
| 가까운 곳에서 조치 | 목적지까지는 무리 없지만 가까운 곳에서 점검하거나 보충하세요 | 타이어 상태 이상, 배터리 또는 연료 부족 |
| 즉시 조치 | 안전한 곳에 정차하거나 출발 전에 먼저 조치하세요 | 문 열림, 주차 브레이크가 걸린 상태에서의 출발 준비. 주행 중 즉시 정차 대상 경고는 종류 확인 후 확정 |

- 제공 영역에 없는 정보(엔진오일 상태, 타이어 공기압 수치, 속도와 가속도 등)는 다루지 않는다.
- 서비스는 "차량이 제공하는 경고와 상태 범위 안에서" 동작한다. 모든 경고등을 해설한다고 약속하지 않는다.

## 4. 주요 기능

### 핵심 기능 (3개)

1. **경고와 상태 해석, 등급 판단**
   - 경고나 상태 이상이 발생하면 의미와 위험도를 정해진 규칙에 따라 판단한다.
   - 주행 중에는 화면을 보지 않아도 되도록 음성 한 줄만 안내한다.
     예: "타이어 상태에 이상이 있습니다. 가까운 곳에서 점검하세요."
   - 정차 후에는 의미와 해야 할 일을 자세히 보여주고, "계속 가도 돼?" 같은 질문에 음성으로 답한다.
   - 등급은 사람이 정한 규칙표로만 판단한다. AI는 설명만 담당하고 등급을 바꾸지 못한다.
   - 배터리가 부족하면 가까운 충전소 안내로 이어준다. 점검이 필요하면 정비소 안내로 이어준다.
2. **출발 전 10초 점검**
   - 시동을 걸면 문, 창문, 주차 브레이크, 타이어, 라이트, 배터리 또는 연료 잔량, 경고 상태를 한 번에 요약한다.
   - 예: "문 하나 열림, 창문 열림, 경고 없음"
   - 처음 타는 차에서 "이 차는 지금 괜찮은가"를 바로 알 수 있다.
3. **정비소 전달 요약**
   - 경고나 상태 이상이 발생한 시점의 정보(날짜, 주행거리, 내용, 판단 등급)를 정리해 정비소에서 보여줄 한 장 요약을 만든다.
   - 같은 항목이 반복되면 강조한다.
   - 앱은 부품 교체 필요성이나 고장 원인을 판단하지 않는다. 기록과 전달만 하고, 판단은 정비사가 한다.
   - 차량 화면을 그대로 보여주는 방식을 기본으로 한다.

### 선택 기능 (시간이 되면)

4. **쉬운 말 모드**: 초보, 고령, 렌터카 사용자용으로 용어 난이도와 말 속도를 조절한다. (말 속도 조절 가능 여부는 확인 필요)

### 이번 범위에서 제외한 것

- 소모품 교환 주기 알림, 정비 이력 관리: 현대차 마이현대 앱이 이미 제공하는 영역이라 중복을 피한다.
- 말로 차량 기능 실행: 차량 내 음성 비서가 이미 음성 명령으로 차량을 제어하므로 중복을 피한다.
- 엔진오일 상태, 타이어 공기압 수치, 속도나 가속도 기반 기능: 공개 SDK·API에서 제공이 확인되지 않아 제외한다.

## 5. 차량 특화성 (폰이 아니라 차에서 해야 하는 이유)

| 기능 | 차에서 해야 하는 이유 | 강도 |
|---|---|---|
| 경고와 상태 해석, 등급 판단 | 경고와 상태는 차량에서 발생하고, 운전 중 음성으로 바로 안내해야 의미가 있다 | 강함 |
| 출발 전 10초 점검 | 시동을 거는 시점의 차량 상태를 차에서 바로 확인한다 | 강함 |
| 정비소 전달 요약 | 차량 화면을 정비소에서 그대로 보여준다. 폰 앱이 더 자연스러울 수 있어 보완이 필요하다 | 보통 |

## 6. 앱이 동작하는 방식

| 상황 | 동작 |
|---|---|
| 출발 전 | 차량 상태를 요약해서 알려준다 |
| 운전 중 | 경고나 상태 이상이 생기면 짧은 음성 한 줄로만 알려준다. 운전을 방해하는 화면 조작은 막는다 |
| 정차 후 | 상세 설명 화면, 질문, 충전소 또는 정비소 안내를 제공한다 |
| 정비소에서 | 정비소 전달 요약을 보여준다 |

네트워크가 불안정해도 기본 안내(해석, 등급 판단)는 끊기지 않도록 한다.

## 7. 사용 시나리오

아래 인물은 이해를 돕기 위한 가상 예시이다.

### 시나리오 1: 렌터카에서 타이어 상태 이상 (중간 등급)

제주도에서 처음 타는 렌터카의 타이어 상태에 이상이 감지됐다.
1. 주행 중 음성 한 줄로 "타이어 상태에 이상이 있습니다. 가까운 곳에서 점검하세요"라고 안내한다.
2. 정차하자 상세 화면에서 의미와 해야 할 일을 확인한다.
3. "숙소까지 가도 돼?"라고 묻자 "이동은 가능하지만 가까운 곳에서 점검하세요"라는 답을 듣는다.
4. 정비소 안내를 받고, 반납 때 보여줄 요약도 남긴다.

### 시나리오 2: 정비소에서 설명이 어려운 상황 (정비소 전달 요약)

직장인이 한 달 전에 경고가 몇 번 떴지만 정확히 기억나지 않는다.
1. 정비소에 가서 정비사에게 "경고가 떴었는데 정확히 뭔지 모르겠다"고 말하기 어렵다.
2. 앱의 정비소 전달 요약을 보여주면 날짜, 주행거리, 내용, 등급이 한눈에 보인다.
3. 정비사와 정확한 정보를 바탕으로 이야기하고, 필요한 작업을 정확히 요청한다.

### 시나리오 3: 부모님 전기차에서 배터리 부족 (쉬운 말 모드)

고령의 부모님이 낯선 전기차를 운전하다 배터리 잔량이 낮아졌다.
1. 쉬운 말 모드가 켜져 있어 천천히, 쉬운 표현으로 "배터리가 부족합니다. 가까운 충전소로 안내할게요"라고 알려준다.
2. 정차 후 화면에서 충전소를 선택해 길 안내를 시작한다.

### 시나리오 4: 새 차 인수 직후 (출발 전 점검)

새 차를 인수하고 처음 시동을 걸었다.
1. "문 하나가 열려 있습니다. 경고는 없습니다."라는 요약을 듣는다.
2. 경고가 없는 정상 상태의 기준을 한 번 확인하며 차에 적응한다.

## 8. 기능별 사용 데이터와 근거

공모전이 공개 SDK·API 활용을 전제로 하므로, 각 기능이 어떤 차량 정보에 기대는지와 확인 상태를 정리한다. 차량 모델에 따라 제공 범위가 다를 수 있어, 앱 시작 시 지원 여부를 확인하고 지원하지 않는 항목은 숨긴다.

| 기능 | 필요한 차량 정보 (제공 영역) | 확인 상태 |
|---|---|---|
| 경고 해석과 등급 판단 | 차량 경고 정보 (Safety) | 영역은 문서에 있음. 어떤 경고가 몇 종류 오는지는 확인 필요 |
| 타이어 상태 판단 | 타이어 상태 (Tire) | 영역은 문서에 있음. 세부 값은 확인 필요. 공기압 수치는 제공이 확인되지 않아 사용하지 않음 |
| 문, 창문, 주차 브레이크, 라이트 점검 | 문 (Door), 창문 (Window), 브레이크 (Brake), 라이트 (Light) | 영역은 문서에 있음 (주차 브레이크 상태, 문 열림과 잠금, 창문 상태, 라이트 상태 조회) |
| 배터리 또는 연료 잔량 | 배터리와 충전 상태 (EvBattery), 연료 부족 경고와 주행가능거리 | 영역은 문서에 있음. 값의 범위는 확인 필요 |
| 정비소 전달 요약 | 경고 정보, 총 주행거리 (Odometer) | 주행거리 영역은 문서에 있음 |
| 충전소 또는 정비소 안내 | 내비게이션 연동 (NaviHelper) | 목적지 설정과 충전사 정보 조회는 문서에 있음. 정비소 검색은 확인 필요 (안 되면 정비소 목록을 직접 준비) |
| 음성 안내와 질문 | 음성 출력, 음성 인식, 대화형 AI (Gleo AI) | 문서에 있음 |

경고 종류가 적게 확인되면 출발 전 10초 점검과 상태 판단을 주력으로 하고 경고 해설은 일부로 줄인다.

## 9. 기존 서비스와의 차이

현대차는 이미 관련 기능을 일부 제공하고 있다.

- 마이현대 앱: 총 주행거리, 배터리 상태, 소모품 정보 관리, 차계부(소비 내역, 정비 내역, 연비 통계), 정비 예약
- 차량 진단: 차량 신호 기반 1차 진단 결과, 서비스센터 찾기, 고객센터 연결
- 차량 내 음성 비서(Gleo AI): 음성 명령으로 차량 제어, 목적지 설정 등

| 구분 | 기존 서비스 | 이 서비스 |
|---|---|---|
| 중심 상황 | 소유주의 차량 관리 | 낯선 차를 운전하는 순간의 불안 해소 |
| 경고와 상태 안내 | 진단 결과 안내 후 서비스센터 연결 | 쉬운 말로 설명하고 3단계로 즉각 판단 (기존 진단의 설명 방식은 확인 필요) |
| 운전 중 사용 | 주로 정차 후 확인 | 주행 중 음성 한 줄 안내 |
| 차량 제어 | 음성 비서가 담당 | 제어는 하지 않고 해석, 판단, 전달에 집중 |
| 정비소 소통 | 정비 이력 관리와 예약 | 경고와 상태 이상 발생 시점 정보를 정비소에 전달 |
| 사용자 | 소유주 또는 승인된 사용자 | 렌터카, 빌린 차 운전자를 포함 (실제 이용 가능 여부는 확인 필요) |

## 10. 기대 효과 (가설)

아래 항목은 검증된 사실이 아니라 가설이며, 설문이나 사례로 확인이 필요하다.

- 낯선 차를 운전할 때의 불안이 줄어든다.
- 위험한 경고나 상태를 방치하는 경우가 줄어든다.
- 정비소에서 증상을 정확히 전달하기 쉬워진다.
- 정비 예약으로 이어지는 연결 고리가 생긴다.

## 11. 안전 설계 원칙

- 판단은 사람이 만든 규칙표로만 한다. AI는 설명을 돕는 역할만 한다.
- 위험 가능성이 있으면 보수적으로 "정차 권고"를 우선한다.
- 부품 교체 필요성이나 고장 원인은 판단하지 않는다. 정비 판단은 정비사가 한다.
- 주행 중에는 운전자를 방해하지 않도록 음성 한 줄로 제한한다.
- 연결이 불안정해도 기본 안내는 동작해야 한다.
- 차량 모델마다 제공하는 정보가 달라, 지원하지 않는 항목은 숨기거나 안내한다.

## 12. 확인 필요 사항

- 차량이 실제로 제공하는 경고 종류와 범위 (가장 큰 미확인 사항)
- 타이어 상태가 어떤 값으로 제공되는지
- 배터리 또는 연료 잔량과 주행가능거리가 어떤 값으로 제공되는지
- 시연 환경에서 경고 또는 상태 이상 상황을 재현할 수 있는지
- 기존 차량 진단이 경고 의미를 쉬운 말로 설명하고 판단까지 해주는지
- 렌터카, 빌린 차 운전자가 마이현대 기능을 이용할 수 있는지
- 정비소 안내 방식과 데이터 출처
- 공모전 공식 심사 기준과 배점
- 공모전 제출 방식 (포스터에는 이메일 제출, 일부 기사에는 홈페이지 신청으로 나와 있음)
