# 💡 아이디어 공유 폴더

팀원끼리 아이디어, 개선점, 참고 자료를 자유롭게 남기는 공간입니다.

## 사용 방법
1. 새 아이디어는 [`_template.md`](_template.md)를 복사해 파일을 하나 만듭니다.
   - 파일명: `날짜_한줄제목.md` (예: `1107_주차카드_사진첨부.md`)
2. 짧은 메모는 [`backlog.md`](backlog.md)에 한 줄로 추가해도 됩니다.
3. 논의가 끝나면 아이디어 파일 맨 위 **상태**를 바꿉니다.

## 상태 표시
| 상태 | 의미 |
|---|---|
| 🟡 제안 | 막 떠오른 아이디어 |
| 🔵 논의 중 | 함께 검토하는 중 |
| 🟢 채택 | 기획서나 개발에 반영하기로 함 |
| ⚪ 보류 | 지금은 안 하지만 나중에 다시 볼 것 |
| 🔴 제외 | 하지 않기로 함 (이유를 남겨 두기) |

## 판단 기준
아이디어를 채택할지 고민될 때 공모전 1차 심사 기준에 비춰 봅니다.
- **차량특화성**: 폰이 아니라 차에서 해야 하는 이유가 있는가?
- **창의성**: Pain Point가 분명하고 기존에 없던 방식인가?
- **기술 활용성**: Pleos SDK를 핵심 기능에 쓰는가?
- **사업성**: 사용자가 계속 쓰고 늘어날 수 있는가?
- **실현 가능성**: 남은 일정 안에 우리가 만들 수 있는가?

> ⚠️ 이 폴더도 심사위원이 볼 수 있으니 실명, 연락처 같은 개인정보는 적지 마세요.
