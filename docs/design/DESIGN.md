# 차곡차곡 디자인 기준

화면을 고칠 때는 이 문서의 색·글꼴·간격만 씁니다. 여기에 없는 색이나 글꼴은 새로 만들지 않습니다.

## 누가, 어디서 보는가
- 운전석에서 팔을 뻗어 닿는 차량 화면. 1~2초 안에 읽고 한 손으로 누릅니다.
- 그래서 한 화면의 주인공은 하나입니다: **앞 운전자가 남긴 쪽지 한 장**.
- 분위기: 계기판이 아니라 **가족이 남긴 쪽지**. 차량 기본 화면(차 상태 표, 검은 계기판)과 닮지 않게 합니다.
- 차 상태는 "기어 P, 배터리 100%" 같은 표로 늘어놓지 않습니다. 넘겨받는 사람이 알아야 할 것만 **문장**으로 적습니다.

## 색
| 이름 | 밝은 종이 (기본) | 어두운 종이 (밤) | 쓰는 곳 |
|---|---|---|---|
| 바탕 | `#F3EFE6` | `#141311` | 화면 전체. Pleos Connect 시스템 화면과 어울리는 따뜻한 종이색 |
| 쪽지 | `#FCFAF4` | `#1E1C19` | 쪽지 한 장의 바탕 |
| 선 | `#D9D2C3` | `#34312B` | 쪽지 테두리, 목록을 나누는 1dp 선 |
| 글자 강 | `#1E1C19` | `#F4F1EA` | 쪽지 글, 주 버튼 바탕 |
| 글자 중 | `#5F5A50` | `#A9A79F` | 설명, 항목 이름 |
| 글자 약 | `#7D776B` | `#7A786F` | 보조 정보, 꺼진 상태 |
| 정상 | `#1F7A48` | `#57C785` | 이상 없음 |
| 주의 | `#A86200` | `#F2B33D` | 가까운 곳에서 조치 |
| 위험 | `#BF3B2B` | `#F0604D` | 출발 전 조치 |

- 시스템이 어두운 테마일 때는 어두운 종이로 바뀝니다. 구성은 같습니다.
- 주조색은 **먹색(`글자 강`) 하나**입니다. 주 버튼은 먹색 바탕에 종이색 글자.
- 초록·노랑·빨강은 **차 상태를 알릴 때만** 씁니다. 장식이나 버튼에 쓰지 않습니다.
- 그라데이션, 반투명 유리 효과, 색 바탕 위의 회색 글자는 쓰지 않습니다.

## 글꼴
- **Asta Sans** 하나만 씁니다 (Pleos Connect 디자인 가이드 지정 글꼴, SIL OFL).
- 크기 단계: 88 / 64 / 56 / 36 / 24 / 22 / 20 / 18 / 15sp. 가장 작은 글자도 15sp 이상.
- 숫자와 자리 이름은 굵게(800), 설명은 보통(400). 굵기 차이로 위계를 만듭니다.

## 구조
- 칸은 **쪽지 한 장뿐**입니다. 그 밖의 구역은 여백과 1dp 선으로만 나누고, 카드 안에 카드를 넣지 않습니다.
- 가로 화면: 왼쪽 넓은 칸(쪽지: 누가, 언제, 어디에, 넘겨받을 때 알 것) | 오른쪽 좁은 칸(지금 확인할 것, 가족 장소, 지난 쪽지).
- 세로 화면: 같은 순서로 위에서 아래로.
- 간격 단계: 8 / 16 / 24 / 40dp. 화면 가장자리 여백 40dp.
- 모서리: 버튼 12dp, 쪽지 6dp.

## 누르는 것
- 높이 88dp 이상. 주 버튼은 화면에 하나(내 쪽지 남기기).
- 보조 버튼은 선 테두리에 글자만.
- 주행 중에 쓸 수 없는 것은 `글자 약` 색으로 흐리게.

## 움직임
- 주행 중 시선을 끌지 않도록 애니메이션을 넣지 않습니다.

## 쓰지 않는 것
- 차 상태를 항목·값 표로 나열하기, 검은 계기판 느낌
- 기본 글꼴(Roboto), 파랑·보라 그라데이션, 알약 모양 꼬리표를 줄줄이 늘어놓기
- 똑같은 모양의 카드 반복, 카드 안의 카드
- 튕기는 효과, 반짝임, 그림자
