## 한 줄 소개

**"차를 넘겨받는 순간, 차가 먼저 알려줍니다"**

GPS가 알려주지 못하는 '지하 2층 B구역 기둥 14'를 음성 한마디로 기록하고, 차를 넘겨받는 사람에게 주차 위치와 차 상태를 차가 먼저 알려주는 **차량 인수인계 앱**

---

## 어떤 문제를 푸나요?

차는 하나인데 운전자는 여럿입니다. 운전자가 바뀔 때마다 필요한 정보가 기억과 말에만 기대어 전달되고, 쉽게 끊깁니다.

| Pain Point | 설명 |
|---|---|
| 🅿️ 지하주차장의 마지막 50m | 층·구역이 비슷한 지하주차장에서 운전한 본인도 위치를 잊고, 넘겨받은 가족은 헤맵니다 |
| 📡 GPS의 한계 | 기존 차량 위치 서비스는 수십~수백 m 오차가 있고, 건물 안의 층·구역은 구분하지 못합니다 |
| 🔧 모르고 넘겨받는 차 상태 | 직전 운전자가 겪은 타이어 이상, 연료 부족, 열어 둔 창문을 다음 사람은 출발한 뒤에야 압니다 |
| 🧠 기억에 기대는 기록 | 휴대폰 메모는 직접 떠올려 앱을 열어야 해서, 바쁜 하차 순간에 대부분 놓칩니다 |

**왜 차에서 해야 하나요?** 주차가 끝나는 순간과 차의 상태를 가장 정확히 아는 것은 차입니다. 그리고 모든 운전자가 반드시 거쳐 가는 유일한 접점도 차입니다.

---

## 기능 4가지

### ① 주차 음성 메모 (핵심)
- 차가 멈추고 **주차 브레이크가 걸리면** "주차 위치를 남길까요?"라고 **먼저 묻습니다.**
- "B2 기둥 14"라고 말하면 원본 음성, 위치, 건물명, 시각, 운전자, 차 상태가 **주차 카드**로 저장됩니다.
- 자주 가는 주차장은 기억해서 **"응" 한마디**로 끝납니다.

### ② 탑승·하차 점검 브리핑 (팀원 아이디어 '낯선 차 적응 도우미' 통합)
| 순간 | 예시 |
|---|---|
| **탈 때** | "엄마가 B2 기둥 14에 주차했어요. 타이어 상태에 이상이 있고, 연료로 40km 갈 수 있어요. 주유소를 안내할까요?" |
| **내릴 때** | "창문이 열려 있어요", "라이트가 켜져 있어요" |
| **운전 중** | 상태 이상이 생기면 음성 한 줄로만 안내하고 주차 카드에 기록 |
| **기록** | "최근 2주간 타이어 이상 3회" → 가족이 함께 보고, 정비소에서 그대로 보여줌 |

**3단계 등급** (사람이 정한 규칙표로 판단)
- 🟢 계속 주행 가능: 이상 없음
- 🟡 가까운 곳에서 조치: 타이어 상태 이상, 연료·배터리 부족 → 주유소·충전소 길 안내
- 🔴 출발 전 조치: 문 열림, 주차 브레이크가 걸린 채 출발 준비

### ③ 음성 장소 핀 → 다시 가기
- "여기 다음에 오자" → 가족 장소 목록에 저장
- "그 빵집 안내해줘" → 바로 길 안내

### ④ 가족 연결
- 차 화면의 QR로 가족 그룹에 참여
- 휴대폰 웹앱(설치 없음, iPhone·Android 모두)에서 주차 카드, 원본 음성, 차 상태 기록 확인

---

## 기존 서비스와 뭐가 다른가요?

| 서비스 | 하는 일 | 차곡차곡 |
|---|---|---|
| 블루링크·마이현대 | GPS로 '어느 건물'인지 | **층·구역·기둥**까지, 가족 운전자 간 인수인계 |
| 차량 음성비서 | 물어보면 답함 | 차를 넘겨받는 순간 **먼저** 알려줌 + 이전 운전자 기록 |
| 휴대폰 메모·지도 앱 | 사용자가 떠올려서 기록 | 차가 주차 순간을 감지해 **먼저** 물어봄 |

---

## 원칙
- 주행 중에는 **음성 한 줄로만** 안내하고, 화면 조작은 정차 중에만 허용
- **실시간 위치 추적 없음**: 주차 시점의 위치만 공유. 원본 음성은 다음 주차 때 자동 삭제
- 등급은 **규칙표로만** 판단 (AI가 바꾸지 않음). 고장 원인은 판단하지 않음
- 차량이 지원하지 않는 항목은 숨기고, 브리핑은 **네트워크 없이도** 동작

## 사용하는 Pleos SDK

| SDK | 용도 |
|---|---|
| Vehicle SDK | 주차 브레이크(Brake), 문(Door), 창문(Window), 라이트(Light), 타이어(Tire), 연료·배터리(Fuel/EvBattery), 주행거리(Odometer) |
| SpeechToText SDK | 주차 메모, 장소 핀, 음성 명령 |
| TextToSpeech SDK | 주차 확인 질문, 탑승·하차 브리핑, 상태 이상 안내 |
| FusedLocation SDK | 주차·장소 좌표, 정지 감지, 자주 가는 주차장 판별 |
| NaviHelper SDK | 저장한 장소, 주유소·충전소 길 안내 |

> 공개 SDK 문서에서 **제공이 확인된 영역만** 핵심 기능에 씁니다. 일반 경고등(Safety 영역)은 어떤 경고가 오는지 확인한 뒤 추가합니다.

## 일정과 개발 범위

| 단계 | 기간 | 범위 |
|---|---|---|
| **1단계** | ~11/15 (1차 접수) | 개발 환경 구축, SDK 연동 검증, 주차 음성 메모 프로토타입, 화면 시안 |
| **2단계** | ~12/3 (2차 PT) | 가족 연결·웹앱, 점검 브리핑과 등급표, 자주 가는 주차장, 장소 핀·내비 연동 |
| 3단계 | 선정 시 | 안정화, 전시용 APK |

**PT 시연 장면**: 차 화면에서 "B구역 기둥 14"라고 말하면, 심사위원 앞 휴대폰에 주차 카드가 바로 뜨고 원본 음성이 재생됩니다.

## 향후 확장 (기획서에만 기재)
- 경고 해설 확대 (일반 경고등), 쉬운 말 모드 (초보·고령 운전자)
- 전기차 충전 바통터치: 충전이 끝나면 근처 가족에게 "차 빼줘" 요청
- B2B: 법인차·카셰어링·렌터카 인수인계 기록
