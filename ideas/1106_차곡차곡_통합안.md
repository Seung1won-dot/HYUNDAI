## 한 줄 요약

**"차를 넘겨받는 순간, 차가 먼저 알려줍니다"**
주차 위치부터 차 상태까지, 음성 한마디로 다음 운전자와 가족에게 이어주는 **차량 인수인계 앱**

> GPS가 모르는 '지하 2층 기둥 14'와 다음 운전자가 알아야 할 차 상태를, 차가 먼저 챙겨서 넘겨줍니다.

## 왜 합쳤나요?

두 아이디어 모두 **"차를 넘겨받는 사람"**의 불편을 다룹니다.

| 기존 차곡차곡 | 팀원 아이디어 (낯선 차 적응 도우미) |
|---|---|
| 가족 차를 넘겨받은 사람: "차 어디 있지?" | 낯선 차를 넘겨받은 사람: "이 경고 뭐지?" |
| 다음 운전자 브리핑 | 출발 전 10초 점검 |

특히 '다음 운전자 브리핑'과 '출발 전 10초 점검'은 거의 같은 순간에 일어나는 기능이라, 하나로 합치면 브리핑이 훨씬 쓸모 있어집니다.
그래서 **차곡차곡을 바탕으로 두고, 팀원 아이디어의 '차 상태를 쉬운 말로 알려주기'를 브리핑에 흡수**하는 방향으로 정리했습니다.

## 기능 구성

### ① 주차 음성 메모 (핵심) · 기존 차곡차곡
- 차가 주차를 감지하면 "주차 위치 남길까요?"라고 먼저 묻습니다.
- "B2 기둥 14"라고 말하면 원본 음성, 위치, 건물명과 함께 **주차 카드**로 저장됩니다.
- 자주 가는 주차장은 기억해 두고 "응" 한마디로 기록을 끝냅니다.

### ② 탑승·하차 점검 브리핑 · ⭐ 이번에 확장한 부분
| 순간 | 동작 | 출처 |
|---|---|---|
| **탈 때** | "엄마가 B2에 주차했어요. 타이어 공기압이 낮고 연료는 15%예요. 문은 모두 닫혀 있어요." | 기존 브리핑 + 팀원의 **출발 전 10초 점검** |
| **내릴 때** | "창문이 열려 있어요", "실내등이 켜져 있어요" | 이번 논의에서 새로 파생 |
| **운전 중 경고 기록** | 경고가 있었으면 주차 카드에 자동 기록 (예: "아빠 운전 중 타이어 경고 2회"). 쌓인 기록은 정비소에서 그대로 보여줄 수 있음 | 팀원의 **정비소 전달 요약**을 인수인계 기록으로 변형 |
| **경고 쉬운 말 해설** | 지원되는 항목(타이어, 연료 부족, 문 열림 등)을 쉬운 말과 **3단계 등급**으로 안내: 계속 주행 가능 / 가까운 곳에서 점검 / 즉시 정차 | 팀원의 **경고 해석과 등급 판단** (축소 적용) |

### ③ 음성 장소 핀 · 기존 차곡차곡
- "여기 다음에 오자"라고 말하면 가족 장소 목록에 저장됩니다.
- "그 빵집 안내해줘"라고 하면 바로 내비 길 안내로 이어집니다.

### ④ 가족 연결 · 기존 차곡차곡
- 차 화면의 QR로 가족 그룹에 참여합니다.
- 가족은 휴대폰 웹앱(PWA)에서 주차 카드와 원본 음성을 확인합니다.

---

## 원칙 (두 아이디어의 원칙을 합침)

- 주행 중에는 **음성으로만** 동작하고, 화면 조작은 정차 중에만 허용합니다.
- 실시간 위치 추적 없이 **주차 시점의 위치만** 공유합니다.
- 원본 음성은 다음 주차 기록이 생기면 자동 삭제합니다.
- 경고 등급은 **사람이 정한 규칙표로만** 판단합니다. AI는 설명만 돕고 등급을 바꾸지 않습니다. *(팀원 아이디어에서 가져옴)*
- 위험 가능성이 있으면 보수적으로 "정차 권고"를 우선합니다. *(팀원 아이디어에서 가져옴)*
- 고장 원인이나 부품 교체 필요성은 판단하지 않습니다. 판단은 정비사의 몫입니다. *(팀원 아이디어에서 가져옴)*

## 팀원 아이디어 반영 내역

| 팀원 아이디어 기능 | 반영 | 방식 / 이유 |
|---|---|---|
| 출발 전 10초 점검 | ✅ 반영 | 탑승 브리핑에 통합 |
| 정비소 전달 요약 | ✅ 변형 반영 | 주차 카드의 경고 기록으로 흡수 |
| 경고 해석과 3단계 판단 | 🔸 축소 반영 | SDK로 받을 수 있는 항목만 우선 적용 |
| 안전 설계 원칙 | ✅ 반영 | 기획서 원칙에 그대로 포함 |
| 렌터카·카셰어링 타깃 | ✅ 반영 | 기획서 '향후 확장(B2B)'의 근거로 활용 |
| 쉬운 말 모드 (초보·고령) | ⚪ 보류 | 핵심 흐름 밖. 확장 계획에 기재 |
| 자주 쓰는 기능 말로 실행 ("와이퍼 켜줘") | 🔴 제외 | 차량 기본 음성비서와 중복, 차량 제어 권한(CONTROL_*) 추가 필요 |
| 모델별 버튼 위치 안내 | 🔴 제외 | 차종별 콘텐츠 제작 부담 큼 |

## 사용 SDK

| SDK | 용도 |
|---|---|
| **Vehicle SDK** | 주차 감지, 연료·배터리, 주행거리, **문·창문·타이어·실내등 상태 (이번에 추가)** |
| SpeechToText SDK | 주차 메모, 장소 핀, 음성 명령 |
| TextToSpeech SDK | 주차 확인 질문, 탑승·하차 브리핑, 경고 해설 |
| FusedLocation SDK | 주차·장소 좌표, 자주 가는 주차장 판별 |
| NaviHelper SDK | 저장한 장소 길 안내 |

> 참고: Pleos Connect Vehicle SDK 권한 문서 기준으로 앱이 접근할 수 있는 영역은 Door, Window/Wiper, HVAC, DrivingMode/Brake/Odometer, EvBattery/Fuel, CarInfo/Display, Light/TurnSignal, SideMirror, Safety/Tire, Seat, Toll입니다. **'경고등' 전용 영역은 목록에 없어서**, 일반 경고등(엔진오일 등)까지 받을 수 있는지는 에뮬레이터에서 확인이 필요합니다.
