# 차곡차곡 디자인 기준

화면을 고칠 때는 이 문서의 색·글꼴·간격만 씁니다. 여기에 없는 색이나 글꼴은 새로 만들지 않습니다.

## 누가, 어디서 보는가
- 운전석에서 팔을 뻗어 닿는 차량 화면. 1~2초 안에 읽고 한 손으로 누릅니다.
- 그래서 한 화면의 주인공은 하나입니다: **마지막 주차 위치**.
- 분위기: 차분하고 믿음직한 계기판. 꾸밈보다 글자와 여백으로 정리합니다.

## 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#101110` | 화면 전체. 밤에도 눈부시지 않은 무채색 (남색 아님) |
| 선 | `#2A2C29` | 구역을 나누는 1dp 선 |
| 글자 강 | `#F4F1EA` | 제목, 값, 주 버튼 바탕 |
| 글자 중 | `#A9A79F` | 설명, 항목 이름 |
| 글자 약 | `#6F6E68` | 보조 정보, 꺼진 상태 |
| 정상 | `#57C785` | 이상 없음 |
| 주의 | `#F2B33D` | 가까운 곳에서 조치 |
| 위험 | `#F0604D` | 출발 전 조치 |

- 주조색은 **아이보리(`글자 강`) 하나**입니다. 주 버튼은 아이보리 바탕에 검은 글자.
- 초록·노랑·빨강은 **차 상태를 알릴 때만** 씁니다. 장식이나 버튼에 쓰지 않습니다.
- 그라데이션, 반투명 유리 효과, 색 바탕 위의 회색 글자는 쓰지 않습니다.

## 글꼴
- **Asta Sans** 하나만 씁니다 (Pleos Connect 디자인 가이드 지정 글꼴, SIL OFL).
- 크기 단계: 88 / 64 / 56 / 44 / 24 / 22 / 18 / 15sp. 가장 작은 글자도 15sp 이상.
- 숫자와 자리 이름은 굵게(800), 설명은 보통(400). 굵기 차이로 위계를 만듭니다.

## 구조
- **카드 안에 카드를 넣지 않습니다.** 구역은 여백과 1dp 선으로만 나눕니다.
- 가로 화면: 왼쪽 넓은 칸(주차 위치) | 세로선 | 오른쪽 좁은 칸(차 상태, 가족 장소, 이전 기록).
- 세로 화면: 같은 순서로 위에서 아래로.
- 간격 단계: 8 / 16 / 24 / 40dp. 화면 가장자리 여백 40dp.
- 모서리: 버튼 12dp. 그 밖의 칸은 모서리를 둥글리지 않습니다 (칸 자체가 없음).

## 누르는 것
- 높이 88dp 이상. 주 버튼은 화면에 하나(주차 위치 남기기).
- 보조 버튼은 선 테두리에 글자만.
- 주행 중에 쓸 수 없는 것은 `글자 약` 색으로 흐리게.

## 움직임
- 주행 중 시선을 끌지 않도록 애니메이션을 넣지 않습니다.

## 쓰지 않는 것
- 기본 글꼴(Roboto), 파랑·보라 그라데이션, 알약 모양 꼬리표를 줄줄이 늘어놓기
- 똑같은 모양의 카드 반복, 카드 안의 카드
- 튕기는 효과, 반짝임, 그림자
